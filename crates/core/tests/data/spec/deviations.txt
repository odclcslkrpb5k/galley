# GitHub's autolink extension (on) links bare URLs and addresses that core CommonMark examples

# Raw HTML tables are tables (M3). This example's only cell is indented into a code block, so
# the table has no cells and makes no table block; the expected HTML still has its empty
# <table>, which the oracle counts as a block.
spec:160 an HTML table with no cells is not a table block

spec:141 tag filter shows <style> as text, as GitHub does
spec:142 tag filter shows <style> as text, as GitHub does
spec:145 tag filter shows <style> as text, as GitHub does
spec:147 tag filter shows <script> as text, as GitHub does
